## Getting Started

### 1. Install Node.js
1. Visit https://nodejs.org/.
2. Download the LTS version.
3. Run the installer and follow the prompts.

### 2. Verify Installation
1. Run `node -v` and `npm -v` to verify that both are installed.

### 3. Clone the Repository
1. Open a terminal.
2. Run `git clone https://github.com/ozduarte/inventory-system.git`.
3. Navigate into the project folder using `cd inventory-system`.

### 4. Install Dependencies
1. Run `npm install` to install the project's dependencies.

### 5. Run the Project
1. Run `npm run dev` to start the development server.
2. Open the local URL displayed in the terminal to view the application.
